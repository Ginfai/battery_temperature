# 电池温度监控 · 安装指南

> 本地工具：装在电脑上，插上 iPhone，实时看电池温度、录制并导出 CSV。**完全离线，不上传数据。**

## Windows 安装

1. **安装 iTunes**（读 iPhone 必需）
   从 [Apple 官网](https://www.apple.com/itunes/download/) 下载并安装。
2. **连接设备**
   用数据线连接 iPhone，手机弹出「要信任此电脑吗？」→ 点 **信任**，输入锁屏密码。
3. **打开主程序**
   解压后双击 **`battmon.exe`**，浏览器自动打开监控页面。

## Mac 安装

1. **连接设备**
   用数据线连接 iPhone，手机弹出「要信任此电脑吗？」→ 点 **信任**，输入锁屏密码。
2. **打开主程序**
   解压后双击 **`battmon`**，浏览器自动打开监控页面。

## Android 手机接入(Wi-Fi 推送电池数据到本机)

同一局域网内

1. 让电脑和手机连**同一个 Wi-Fi**。
2. 打开监控页面 → 点右上角 **「Android 设备配置」**按钮 → 弹出的窗口里能看到:**服务器地址(IP)、端口、接入 Token**。
3. 安装配套的 Android 采集 App,在设置页填入上面三个值,点 **「保存并开始采集」**。
---

## 录制与导出

- 页面点 **「● 开始录制」**，停时点 **「■ 停止录制」**。
- 下方「录制会话」点 **data.csv** 下载数据、**meta.json** 查看元数据。

## 常见问题

**页面显示「未检测到 usbmuxd」**
Windows 用户多半没装/装错 iTunes，回看第 1 步。macOS 不需要装。

**页面显示「待配对」**
iPhone 没点「信任」，重新插线在手机上点「信任」。

**浏览器没自动打开**
手动访问 `http://127.0.0.1:8000`。

**端口被占用**
改端口启动：`battmon.exe --port 9000`（Mac 同理 `./battmon --port 9000`）。
